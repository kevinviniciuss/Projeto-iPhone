## Sobre 
  Projeto feito para praticar JavaScript, manipulação do DOM e criação dinâmica de elementos.

## Funcionalidades
📱 Navegação entre modelos de iPhone  <br>
⚡ Criação dinâmica dos cards com JavaScript <br>
🖱️ Alteração de conteúdo ao clicar nos botões <br>
🎨 Interface estilizada inspirada no site da Apple <br>
🧩 Manipulação do DOM em tempo real <br>
📂 Organização de componentes com HTML, CSS e JS <br>
🔄 Troca dinâmica de informações e imagens <br>
📲 Layout responsivo e moderno <br>

## Objetivo

Esse projeto foi desenvolvido apenas para estudos e testes de JavaScript, principalmente:

- Manipulação do DOM
- Eventos de clique
- Criação dinâmica de elementos
- Organização de componentes na interface
